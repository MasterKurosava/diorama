# @dioramajs/blocks

Effects for cards and buttons in Diorama.

## Effects

[`beam`](https://dioramajs.dev/docs/effects/beam), [`glow`](https://dioramajs.dev/docs/effects/glow), [`shine`](https://dioramajs.dev/docs/effects/shine)

## Install

Sites install `dioramajs`, which loads this package when an element needs it:

```bash
npm install dioramajs three
```
