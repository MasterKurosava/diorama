# @dioramajs/transitions

Page transitions for Diorama: keyed elements fly from one page to the next, and page covers hide the swap on any router.

## Install

Sites install `@dioramajs/diorama`, which loads this package when an element needs it:

```bash
npm install @dioramajs/diorama three
```
