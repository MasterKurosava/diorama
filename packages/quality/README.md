# @dioramajs/quality

Adaptive quality for Diorama: a tier per device from its GPU, lowered when frames are missed, that caps the pixel ratio and the cost of each effect.

## Install

Sites install `@dioramajs/diorama`, which loads this package when an element needs it:

```bash
npm install @dioramajs/diorama three
```
