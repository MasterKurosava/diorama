# @dioramajs/effects

Effects on DOM elements: `effect()`, the runtime that keeps them in step with layout and scroll, and `kit`, the helpers the built-in effects are written with.

## Install

Sites install `@dioramajs/diorama`, which loads this package when an element needs it:

```bash
npm install @dioramajs/diorama three
```
