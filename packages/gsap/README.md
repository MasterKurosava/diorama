# @dioramajs/gsap

GSAP and ScrollTrigger for Diorama: tweens and the canvas share one ticker, and pins and scrubs drive effects.

## Install

Sites install `dioramajs`, which loads this package when an element needs it:

```bash
npm install dioramajs three
```
