# @dioramajs/particles

Particle effects for Diorama.

## Effects

[`confetti`](https://dioramajs.dev/docs/effects/confetti), [`drops`](https://dioramajs.dev/docs/effects/drops), [`emoji`](https://dioramajs.dev/docs/effects/emoji), [`snow`](https://dioramajs.dev/docs/effects/snow), [`sparkles`](https://dioramajs.dev/docs/effects/sparkles)

## Install

Sites install `dioramajs`, which loads this package when an element needs it:

```bash
npm install dioramajs three
```
