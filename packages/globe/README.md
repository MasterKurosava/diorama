# @dioramajs/globe

An interactive globe for Diorama, with markers and arcs.

## Effects

[`globe`](https://dioramajs.dev/docs/effects/globe)

## Install

Sites install `@dioramajs/diorama`, which loads this package when an element needs it:

```bash
npm install @dioramajs/diorama three
```
