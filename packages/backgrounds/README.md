# @dioramajs/backgrounds

Shader backgrounds for Diorama.

## Effects

[`blobs`](https://dioramajs.dev/docs/effects/blobs), [`clouds`](https://dioramajs.dev/docs/effects/clouds), [`dots`](https://dioramajs.dev/docs/effects/dots), [`gradient`](https://dioramajs.dev/docs/effects/gradient), [`grid`](https://dioramajs.dev/docs/effects/grid), [`stars`](https://dioramajs.dev/docs/effects/stars), [`waves`](https://dioramajs.dev/docs/effects/waves)

## Install

Sites install `dioramajs`, which loads this package when an element needs it:

```bash
npm install dioramajs three
```
