# @dioramajs/data

Charts, graphs, heatmaps and maps for Diorama, drawn from data in the markup.

## Effects

[`chart`](https://dioramajs.dev/docs/effects/chart), [`graph`](https://dioramajs.dev/docs/effects/graph), [`heatmap`](https://dioramajs.dev/docs/effects/heatmap), [`map`](https://dioramajs.dev/docs/effects/map)

## Install

Sites install `dioramajs`, which loads this package when an element needs it:

```bash
npm install dioramajs three
```
