# @dioramajs/render

The renderer of Diorama: three.js `WebGPURenderer` with a WebGL 2 fallback, a GPU probe and on-demand frames.

## Install

Sites install `@dioramajs/diorama`, which loads this package when an element needs it:

```bash
npm install @dioramajs/diorama three
```
