# @dioramajs/audio

Audio-reactive effects for Diorama.

## Effects

[`beat`](https://dioramajs.dev/docs/effects/beat), [`visualizer`](https://dioramajs.dev/docs/effects/visualizer)

## Install

Sites install `dioramajs`, which loads this package when an element needs it:

```bash
npm install dioramajs three
```
