# @dioramajs/model

3D objects and glTF models for Diorama: a viewer with turntable and drag, product boxes, books, devices, exploded views and hotspots.

## Effects

[`book`](https://dioramajs.dev/docs/effects/book), [`box`](https://dioramajs.dev/docs/effects/box), [`coin`](https://dioramajs.dev/docs/effects/coin), [`device`](https://dioramajs.dev/docs/effects/device), [`explode`](https://dioramajs.dev/docs/effects/explode), [`hotspots`](https://dioramajs.dev/docs/effects/hotspots), [`label`](https://dioramajs.dev/docs/effects/label), [`model`](https://dioramajs.dev/docs/effects/model), [`vinyl`](https://dioramajs.dev/docs/effects/vinyl)

## Install

Sites install `dioramajs`, which loads this package when an element needs it:

```bash
npm install dioramajs three
```
