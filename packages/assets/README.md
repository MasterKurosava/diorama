# @dioramajs/assets

Asset loading for Diorama: one cache with preload and progress, and glTF with Draco, Meshopt and KTX2.

## Install

Sites install `@dioramajs/diorama`, which loads this package when an element needs it:

```bash
npm install @dioramajs/diorama three
```
